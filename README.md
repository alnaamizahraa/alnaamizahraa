## Break Through Tech AI Experience

### AI Studio Project Contributor — Ursa Space Systems
**Fall 2026 | Satellite Cloud Detection**

Through Break Through Tech AI, I collaborate on a team project exploring cloud detection in high-resolution optical satellite imagery. The project compares classical image-processing methods with a pretrained cloud detection model.

**My individual contribution:**

- Developed a Python prototype for a HOT-style cloud detection baseline.
- Fitted a clear-sky relationship between red and blue image channels using reviewed development pixels.
- Selected the detection threshold using development-set F1.
- Evaluated the frozen configuration against human-reviewed masks using the shared evaluation pipeline.
- Documented results, limitations, and reproducible notebook steps.
- Submitted my notebook and results through a pull request that was reviewed and merged.

**Evaluation summary:**

The dataset contained 45 reviewed patches, split into 30 development and 15 test patches, with patches grouped by parent tile. The fitted HOT follow-up achieved:

| Test metric | Result |
|-------------|--------|
| Precision | 87.62% |
| Recall | 86.62% |
| F1 | 87.12% |
| Intersection over Union | 77.17% |

These results use single-reviewer reference masks and normalized display RGB. The fitted experiment followed inspection of earlier baseline test results, so it is reported as a follow-up evaluation. The split separates parent tiles within the same events.

[Team repository](https://github.com/Break-Through-Tech/Ursa-Space-Systems-1D-cloud-detection-in-very-high-resolution-optical-satellite-imagery) · [Merged contribution: PR #28](https://github.com/Break-Through-Tech/Ursa-Space-Systems-1D-cloud-detection-in-very-high-resolution-optical-satellite-imagery/pull/28)
